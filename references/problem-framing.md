# Problem Framing

Use this first when the request is vague, overloaded, or still mixing evidence gathering with interpretation. The goal here is to fill `Task Purpose` and the framing parts of `Current Context` in `research-context.md`.

## Checklist

- State the deliverable in one line: `research-context.md`.
- State the exact question in one line.
- State what decision this work is supposed to unblock.
- Name the evidence sources and why each one matters.
- State what has already been tried.
- State what is out of scope.
- State what must not change or what assumptions are fixed.

## What To Extract

- Goal of the task
- Core question
- Decision to unblock
- Scope limits
- Constraints
- Prior attempts
- Fixed assumptions

## Section Skeleton

```text
## Task Purpose

Goal:
<what this file is for>

Core question:
<what exactly needs to be determined>

Decision to unblock:
<what this analysis will help decide>

Out of scope:
- <explicitly excluded item>

Constraints:
- <scope, platform, evidence, or time limit>

Fixed assumptions:
- <assumption>

What has already been tried:
- <attempt>
- <attempt>
```
